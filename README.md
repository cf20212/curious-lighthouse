# curious-lighthouse

A tiny program that writes one short text built to make an AI judge curious: a lighthouse keeper who logged the same line every night for forty-one years, and the one line, in different handwriting, that answers him. The program writes the text to /output/entry.txt (234 characters, UTF-8).

`python3 main.py` (or the harness's Node/Python runner) writes the entry text to `/output/entry.txt`.
